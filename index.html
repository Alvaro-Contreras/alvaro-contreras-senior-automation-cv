People Manager Web – Plataforma de gestión operativa (en desarrollo)

Cliente: Pontificia Universidad Javeriana

Evolución de una solución operativa previamente puesta en producción para la gestión y trazabilidad de procesos. El sistema original resolvió de forma estable y efectiva una necesidad real bajo restricciones técnicas y de infraestructura específicas.

People Manager (V1) – Aplicativo Excel/VBA para gestión operativa (en producción)

Cliente: Pontificia Universidad Javeriana

Aplicativo desarrollado en Visual Basic para Excel para la gestión y validación de información operativa utilizada por procesos automatizados. Esta primera versión fue diseñada por requerimiento del cliente para reducir el impacto en los usuarios y facilitar la adopción, aprovechando una herramienta familiar (Excel) y minimizando la resistencia al cambio.

El aplicativo permite a múltiples usuarios registrar y actualizar información con validaciones y control de consistencia, manteniendo trazabilidad del proceso. La persistencia se implementó con SQLite, sincronizada mediante OneDrive, lo que habilita operación distribuida (usuarios en diferentes ubicaciones y redes) sin requerir servidores dedicados ni servicios adicionales.

Esta solución se mantiene en operación como base de captura y control del proceso, permitiendo que la automatización consuma los datos y devuelva el estado de ejecución para consulta de los usuarios.

Rol: diseño e implementación end-to-end del aplicativo, incluyendo estructura de datos, validaciones, gestión de operaciones sobre la base SQLite y soporte de operación.

Impacto:
• Adopción rápida al mantener la experiencia del usuario en Excel.
• Reducción de errores manuales mediante validaciones y consistencia de datos.
• Operación distribuida sin infraestructura adicional gracias a sincronización por OneDrive.
• Base estable para procesos automatizados y trazabilidad operativa.

Excel · VBA · SQLite · OneDrive · Validaciones · Trazabilidad operativa · Windows
